# NERextraction

SportExtract adalah sebuah aplikasi berbasis website yang dirancang untuk melakukan ekstraksi informasi otomatis dari berita olahraga berbahasa Indonesia menggunakan metode Named Entity Recognition (NER).
Model NER yang digunakan pada penelitian ini adalah IndoBERT, yang telah terbukti efektif pada perancangan ini dalam memahami konteks bahasa Indonesia.

# Tech Stack
- Python
- PyTorch
- Hugging Face Transformers
- IndoBERT
- Flask
- HTML & CSS

# Model yang Digunakan
- Model: indobenchmark/indobert-base-p1
- Label Entitas yang Digunakan: ATLET, TIM, ORGANISASI, KEJUARAAN, STADION, STATISTIK, PENGHARGAAN, POSISI, KEWARGANEGARAAN, UMUR, TANGGAL, SKOR, AKSI, ALASAN_PERISTIWA
