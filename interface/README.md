# 🏆 SportExtract - Ekstraksi Informasi Berita Olahraga

Sistem ekstraksi entitas (NER) untuk berita olahraga berbahasa Indonesia menggunakan IndoBERT.

## ✨ Fitur

- ✅ Ekstraksi 5W1H dari berita olahraga
- ✅ Web Scraping dari DetikSport, Kompas Sport, BolaSport
- ✅ Multi-label NER dengan IndoBERT

## 🚀 Cara Menggunakan

1. Pilih mode input (Teks atau URL)
2. Klik "Ekstrak Informasi"
3. Lihat hasil dalam format 5W1H
